    Manage Worlds

    These control the world-picker page and the Game Links bubbles. The "Live" world is the one this dashboard actually shows data for — it can't be removed or renamed (slug), but its display name and color are still editable. For a world logo, click Browse… to upload an image (PNG/JPG/WebP/GIF/SVG, 10 MB max), then Save Worlds; the ✕ next to a logo removes it. The Subtext box sets the line under the world's name on the Pick a World page; leave it blank to use the default shown in grey.

    Manage Links

    Add, remove, reorder, recolor, and regroup the buttons shown in the Community Links dropdown. Buttons with the same group name cluster together. For a button icon, click Browse… to upload an image (PNG/JPG/WebP/GIF/SVG), then Save Links; with no icon the button shows a lettered circle.
