# Welcome

This is the "Server News" section, shown at the top of the public page. Edit it from the admin panel's Site Content editor.

* Announce mod updates, restarts, or rule changes here.
* This content supports Markdown, and `>>text<<` blocks for collapsible sections.

**How does the event system work?**

If you've set up the optional `storms.sh`/`caretaking.sh` event scripts (see the README), the next scheduled event and any active one will show automatically above the map. Otherwise, this section is a normal place to post server news and patch notes.
